# Inter font (test images only)

`Inter-Regular.ttf` and `Inter-Bold.ttf` are the static TrueType fonts of Inter 4.0 by The Inter
Project Authors (https://github.com/rsms/inter, release `v4.0`, file `Inter-4.0.zip`, folder
`extras/ttf/`). They are used only by `scripts/make-specimens.py` to print the fictitious SPECIMEN
documents the worker's tests read. They are never shipped to riders or deployed.

Licence: SIL Open Font License 1.1 (`OFL.txt`, the `LICENSE.txt` of the release), with no Reserved
Font Name. The OFL allows use, modification and redistribution, including commercially, as long
as the font itself is not sold on its own and keeps its licence.
